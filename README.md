# 📖 3D Book Portfolio Website

An interactive **3D portfolio website** designed like a flipping book with **smooth animations, custom cursors, and typing effects**.  
It creates an immersive way to showcase skills, projects, and contact details.

## ✨ Features
- 3D book-style page turning  
- Smooth intro & glow animations  
- Custom cursor with effects  
- Auto typing text animation  
- Keyboard navigation (← →)  
- Responsive mobile design  
- Contact form with EmailJS   

## 🛠 Tech
- HTML, CSS, JavaScript  
- EmailJS for contact form
